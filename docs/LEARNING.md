# 语境学习与表达偏好

整理提示词在`prompts/memory.md`，通过`memory.system_prompt_file`配置；每次整理读取，修改提示词下一批生效。协议及数据限制仍由程序控制。配置项修改后重启监听。

## 学什么

- member：某个人在什么语境下怎样表达；明确要求ds怎样回应或不要怎样回应。
- group：这个群里多个成员共享的词、表情用法。
- bot：ds从成熟群内用法中逐渐吸收、与核心人格相容的表达偏好，仅在本群生效。

习惯、事实、性格推测、互动偏好分别理解。“经常用”不等于“喜欢ds模仿”；反话、自嘲或一个表情不能直接形成性格评价或好感变化。完整对话中的旧发言和BOT原话只帮助理解；新增证据必须来自本人未处理的新消息。BOT自己的发言、沉默、无人反对不能充当成功反馈。昵称不是身份键，改名仍归属于同一wxid。

## 证据与成熟

程序根据真实来源时间和ID累计，不接受模型自行填确认次数。个人习惯至少3个独立场景、跨两天；群内用法至少5个独立场景、3位成员、跨两天。同一表达同一成员10分钟内的重复观察不累计；群内场景总次数也按至少10分钟间隔计算，重叠窗口不重复。

成员明确的表达/回应偏好可以立即确认，明确拒绝立即记录为blocked；普通重复用法先是candidate。反例使对应解释退回候选，之后需新的跨场景证据；同一个词在不同语境可有不同解释。ds自身偏好必须引用成熟group记录的basis并有新成员发言支持，不能从自己的输出凭空晋级。

候选7天、稳定个人习惯90天、群内用法和ds偏好30天无新证据后清理。每人最多5条稳定表达习惯，全群最多10条稳定用法、5条ds偏好、40条候选。读取旧记忆不续期。

普通回答、搜索最终回答和主动接话共享相关表达背景，每轮最多2条、300字符，计入原有1200字符记忆预算；相关事实和明确偏好优先。候选不注入回答，不匹配的群内用法不注入；学到不等于每次都用，不复读、不宣布学习或打分过程。表情关闭时仍理解群友原文，但不主动用表情装饰；[微笑]仍不用于示好、感谢、安慰或友好收尾。

## 何时整理

保留@回复最终分片确认后的整理，另加入活跃闲聊整理。被动默认最近300秒至少10条尚未处理的有效成员文字消息、至少2位成员，最短每300秒登记一批。相同成员相同内容刷屏不增加有效计数，单独表情可以参与表达观察。ds是否发言不阻止学习；学习本身不发送任何微信消息。

两种任务统一队列、独立任务ID和来源去重键，按窗口先后处理。被动任务只在前台回复队列空闲时登记，启动前再次排除已整理的重叠消息，避免同一窗口重复请求。后台最多一个、前台优先且可抢占，总API并发最多2。仍使用deepseek-flash、enabled/max思考、8192 tokens、90秒超时；每批最多3条表达增量。失败不提交部分结果，后台延后重试，被动失败至少等待300秒。

活跃闲聊同样更新事件、印象和好感度；只允许本人直接来源，好感每批最多±3、每天累计变化幅度最多10。已识别的纯表情来源不能单独形成性格印象或好感变化。

## 配置与维护

```json
"memory": {
  "system_prompt_file": "prompts/memory.md",
  "learning": {
    "enabled": true,
    "passive_enabled": true,
    "window_seconds": 300,
    "min_new_messages": 10,
    "min_senders": 2,
    "min_interval_seconds": 300
  }
}
```

旧档案保留schema=1并增加可选learning字段，学习记录和证据仍在同一私有memory.json，附加提示词投影可重建。不保存整段对话、图片或内部推理。第一次启用以当前接收游标为基线，不补扫历史，不给旧记忆伪造次数或日期；关闭后重新启用不追溯关闭期间的学习证据。

状态只提供候选/稳定数量、被动任务窗口、阶段及安全错误。显式查看可能显示私人记忆，应按原权限保管：

```bash
python3 -m wxbridge memory status
python3 -m wxbridge memory show --member wxid_xxx
python3 -m wxbridge memory show --scope group
python3 -m wxbridge memory show --scope bot
```

修改前停止监听并取得原单实例锁；旧人物命令兼容：

```bash
python3 -m wxbridge memory correct --scope group --entry 记录id --text-file correction.txt
python3 -m wxbridge memory forget --scope bot --entry 记录id
python3 -m wxbridge memory clear --scope group
```

遗忘某人同步移除其学习证据，重新计算群内用法并移除不再成立的ds偏好。纠正群用法会移除旧的衍生ds偏好，等待后续新证据重新选择。遗忘保留处理水位，旧任务不能把同一来源学回来。

离线测试使用合成对话和可控时钟验证跨天；上线首日只应看到候选或明确偏好，自动形成的稳定习惯等待真实跨天证据。
