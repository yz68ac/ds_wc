# 关系语气的优先级与六档行为

`wxbridge/storage/relationships.py`中的`AFFINITY_PROFILES`统一保存六档边界、名称、简短提示和实际回复约束；`AFFINITY_BANDS`由它生成，不再维护两套行为阈值。边界保持0–19、20–39、40–59、60–74、75–89、90–100，不再为每档叠加下段/中段/上段指令，也不新增50分分界。

六档通过一句话里的回应选择体现：疏远时平静回答眼前内容；有距离时礼貌确认处境；普通相处时就事接梗、有自己的态度；有好感时接住感受或贴题关心；亲近时少客套、调侃和顺手提醒；很亲近时在示弱或示好的具体情境下更柔软。低档不用敷衍词表演厌烦，高档不自动暧昧、撒娇或贬低别人。人格保留温暖、独立和嘴硬，不默认对所有人投入同样关心。

当前回应对象的有效好感、熟悉度、信任及有效期内情绪由主进程读取，作为数字/枚举快照传给生成工作进程。程序据此生成独立的`【本轮关系语气】`系统指令，位于人格之后，不混在普通事件记忆里，也不占1200字附加记忆预算。原聊天预算和完整提问不因它被截断；没有记忆或成员不匹配时不注入。不给系统指令拼接昵称、记忆正文、来源证据、情绪理由或稳定成员ID。

只作用于本次实际回应的成员，不把最后出现者或其他高/低好感成员的状态套给目标。正常@和关键词完整回复共用同一入口；图片重建提示词时替换同一受控区块，不重复叠加；搜索继续使用原系统消息。自然接话在参与判断选定目标后，只把对应成员的关系快照交给正文生成，参与判断规则/次数不变。

核心人格、具体互动偏好与明确拒绝保持。低熟悉度限制擅自亲昵称呼、习惯和共同经历假设，允许对方明确认可的普通称呼；低信任限制承诺和保证，事实核验不按信任高低预判，均不把高好感抹成普通态度。短时情绪只轻微影响当下反应，平静不额外注入。相处偏好只覆盖相处方式，不覆盖事实核验与必要信息。任何档位都对明确痛苦、紧急求助给得体回应和必要帮助，不故意答错、漏关键条件或静默丢任务。关系差异不报分数、档位或内部编号，也不靠每条多写一段、固定话术或额外润色请求实现。

本次不调整已有分数、评分提示词、加减分限幅、衰减规则、主动入场阈值、模型深度或实际服务器配置。运行链路没有新增API请求或额外界面操作。离线回归验证注入优先级、目标隔离和链路传递；合成生成对照作为独立检查，不发到群里，也不写进人物记忆。小样本只用于发现退化和观察差异，不当作统计效果证明。
