# 关系语气的优先级与六档行为

`wxbridge/storage/relationships.py`中的`AFFINITY_PROFILES`统一保存六档边界、名称、简短提示和实际回复约束；`AFFINITY_BANDS`由它生成，不再维护两套行为阈值。六档分别强调：明显冷淡且不延伸、克制疏离、普通群友自然交流、有好感而更愿意互动、熟人式嘴硬关心与调侃、明显亲近与适度依恋。每档另按所在区间的下段/中段/上段控制表达力度，避免跨线突然换人格。

当前回应对象的有效好感、熟悉度、信任及有效期内情绪由主进程读取，作为数字/枚举快照传给生成工作进程。程序据此生成独立的`【本轮关系语气】`系统指令，位于人格之后，不混在普通事件记忆里，也不占1200字附加记忆预算。原聊天预算和完整提问不因它被截断；没有记忆或成员不匹配时不注入。不给系统指令拼接昵称、记忆正文、来源证据、情绪理由或稳定成员ID。

只作用于本次实际回应的成员，不把最后出现者或其他高/低好感成员的状态套给目标。正常@和关键词完整回复共用同一入口；图片重建提示词时替换同一受控区块，不重复叠加；搜索继续使用原系统消息。自然接话在参与判断选定目标后，只把对应成员的关系快照交给正文生成，参与判断规则/次数不变。

核心人格、具体互动偏好与明确拒绝保持。低熟悉度限制亲昵称呼和共同经历假设，低信任限制承诺及事实采信，均不把高好感抹成普通态度；短时情绪只影响当下反应。低好感可以冷淡短答，但不故意编错事实、漏掉专业问题的关键条件或静默丢任务。关系差异通过语气体现，不报分数、档位或内部编号，也不靠每条多写一段、固定话术或额外润色请求实现。

本次不调整已有分数、评分提示词、加减分限幅、衰减规则、主动入场阈值、模型深度或实际服务器配置。没有新增API请求或额外界面操作。离线回归验证注入优先级、目标隔离和链路传递；自然语言效果仍由实际生成决定。
