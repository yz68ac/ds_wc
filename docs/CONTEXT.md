# 当前对话、引用与人物记忆

常规 @ 和主动参与都保留配置的完整近期窗口；默认仍为五分钟，人物附加记忆预算仍为 1200 字。字符预算不足时减少完整记忆行，不裁剪聊天原文。当前提问、明确引用和最近连贯对话优先于人物旧事件。

## 记忆选择

`storage/memory_selection.py` 使用本地词面匹配，不增加 API、embedding 服务或依赖。事件、短期情景与特定兴趣按当前成员原话和明确选中的引用筛选；英文名称不匹配的旧作品、游戏不会因为泛泛措辞混入。中文按去常见词后的二至四字片段保守匹配。

稳定的回答、称呼等交互偏好及普通暂时印象仍可参考。明确问“还记得我以前玩什么游戏吗”时允许在本人记录里回忆旧话题；这条例外不扩大到其他人的记忆，也不覆盖本轮明确指定的作品。

机器人自己此前自由生成的话不用于激活旧话题记忆，避免一次说错后反复自证。用户明确引用的内容仍参与理解。筛选只决定本轮输入，不删除记忆、不续期、不修改好感/信任或处理水位。

词面匹配是保守筛选，并非语义搜索；未出现过的别名、跨语言说法可能漏选。没有匹配到旧事件时仍保留完整近期聊天，不让模型靠记忆猜一个当前没有依据的对象。

## 先判断回应对象，再使用对应记忆

主进程在同一份聊天快照上，为候选消息准备只读记忆片段，按消息 ID 绑定；同一成员的不同引用也分别处理。介入判断只读聊天及机会元数据，不把全部人物旧事件交给判断模型。

判断确定 `reply_to` 后，原工作进程仅取该消息对应的片段构造正文输入；不读数据库或记忆文件，不再按最后发言者猜测应优先谁。判断和正文仍共用原期限、并发位置和抢占机制。通常仍是一次介入判断、决定发言后一次正文请求；原有超长短答的一次重写上限不变。

最终输入增加 `reply_target`：目标消息/成员、附近消息 ID、上一条机器人发言及是否含引用。所有消息保留发送时间，用于识别间隔和省略指代；不会复制或删掉整段历史。

## 一致的身份与引用

`ai/identity.py` 为同一轮生成共享成员编号。BOT 由稳定账号 ID 确认；昵称相同、改名或昵称伪装成 BOT 都不会改变身份。常规 @、主动参与及嵌套引用共用映射，引用数据显式带 `member=BOT/U1/...`；缺少作者 ID 时标为 UNKNOWN，不凭昵称补身份。

## 验证

`tests/test_context_focus.py` 用合成群聊回归旧游戏干扰、中文话题、个人回忆、过期/预算、机器人错误自我强化、同名作者、嵌套引用、多人目标选择及冻结快照。模型替身确认判断不见旧事件、正文只使用目标片段，并保持两阶段调用次数。

上线仍保留服务器实际配置、人格、密钥、记忆、未决发送及接收游标；不通过清空这些数据解决上下文问题。
